Organización del sistema:


controlador 
	|
	|-----bancos
	|      |
	|      |--id
	|      |--cant_celdas
	|      |--pos pin sr (siempre cero en principio)
	|      |
	|      |------shift register
	|      |		|
	|      |		|--data
	|      |		|--clock
	|      |		|--latch
	|      |
	|      |-------mux
	|      |		|
	|      |		|--bit 0
	|      |		|--bit 1
	|      |		|--bit 2
	|      |		|--adc
	|      |
	|      |-------Celda
	|       		|
	|       		|--id
	|       		|--estado_actual
	|       		|--prox_estado
	|       		|--posición pin mux
	|       		|--pos pin sr	
	|
	|
	|--cant_bancos
	|--buses
	
	
Desde cada banco se maneja el shift register, pero las ordenes de latch y clock se envian SI O SI desde el controlador,
ya que esos pines son compartidos entre todos los bancos.
Es muy importante cumplir eso ultimo, en caso de configurar el latch desde banco, podemos eliminar la información del 
resto de los bancos.

**------------------------------------------------------------**
La idea de los estados, 
	si actual y prox son iguales : No hay cambios pendientes
	si actual y prox son distintos: Hay cmabios pendientes
**------------------------------------------------------------**


Controlador manda la instrucción -> banco aplica estados -> se actualiza el estado de celdas

Contralador manda la instruccion de aplicar estados -> banco aplica la logica -> celda actualiza sus estados



Para el switching

**------------------------------------------------------------**
Banco:
- calcula qué celdas quiere ON/OFF según modo/fase
- informa si queda alguna celda ON

Controlador:
- decide transiciones seguras
- aplica frames completos a todos los SR
- maneja delay/dead-time

**------------------------------------------------------------**

Casos de switching:

actual 0 celdas ON -> proximo 0 celdas ON
    sw banco ON, celdas OFF
    un latch alcanza

actual 0 celdas ON -> proximo alguna celda ON
    paso 1: sw banco OFF, celdas OFF
    latch
    delay
    paso 2: sw banco OFF, celdas segun switching
    latch
    
actual alguna celda ON -> proximo alguna celda ON
    sw banco OFF, celdas segun switching
    un latch alcanza

actual alguna celda ON -> proximo 0 celdas ON
    paso 1: sw banco OFF, celdas OFF
    latch
    delay
    paso 2: sw banco ON, celdas OFF
    latch
